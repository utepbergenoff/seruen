# Качество синтетического сэмпла

Источник: записи, созданные для разработки по плану v2.1. **Не выгрузка OSM, не проверенные заведения.** Дата создания: 17.10.2026. В каждом ответе API data_kind=sample и предупреждение; внешние ссылки на посещение отключены.

- В файле: 28 записей.
- Валидных уникальных после загрузчика: 24.
- Дубликатов удалено: 2.
- Мусорных записей отброшено: 2 (координата 999 и имя из знаков вопроса).
- Часы отсутствуют у 1 из 24; рейтинг и описание отсутствуют у той же записи.
- Присутствуют расписание off, бар 18+, wheelchair=no, событие без источника.
- Значения рейтингов, расписаний и часов проверки — фикстуры для проверки логики. Они ничего не доказывают о реальных местах.

Индекс: локальные LSA-векторы, 23 измерения для 24 документов; хранится в data/index/lsa.json и привязан к SHA-256 нормализованных POI. Пересборка: make index. При несовпадении отпечатка сервер автоматически использует BM25, не устаревшие векторы.

Финальный отчёт качества реальных данных готовит Ерлан. Его цифры нужно подставить после получения снимка, затем повторить проверки и пересборку.
