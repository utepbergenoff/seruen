## Что в папке

| Файл | Что это |
|---|---|
| `c/` | все фото с готовыми именами `team-<место>-<район>-<N>.jpg` — так же, как в `frontend/img/places/c/` |
| `places.json` | кто/что/где: место, `poi_id`, координаты, ссылка 2ГИС, для каждого фото — описание и из какой исходной папки оно |
| `index_entries.json` | готовые записи для `frontend/img/places/index.json` |
| `review_entries.json` | готовые записи (SHA-256) для `data/photo_identity_review.json` |
| `merge.py` | добавляет всё в проект одной командой и проверяет ошибки |

Номер в начале строки = номер исходной папки у Ерлана. `<район>`: `mega` — внутри/у Mega Silk Way, `expo` — остальные.

## Как добавить (≈10 минут)

Из корня репозитория seruen:

```bash
git checkout main && git pull
git checkout -b feat/expo-photos
python photos/expo/merge.py            # только проверка, ничего не меняет
python photos/expo/merge.py --apply    # копирует фото и дописывает 2 JSON-файла
python -m pytest -q tests/test_grounded_release.py
npm test
git add frontend/img/places data/photo_identity_review.json
git commit -m "Add Yerlan's photos of 27 places near EXPO"
```

Потом PR в `main`. После слияния нужны **оба** деплоя:
1. **Netlify** — сам сайт с фото и `index.json`.
2. **Render (бэкенд)** — `data/photo_identity_review.json` живёт в бэкенде. Без передеплоя сервер не узнает новые
   хеши и **скроет все новые фото**.

Проверка на сайте: точка у EXPO, запрос «кофе» или «поесть» → у Line Brew, Paul, Noble и др. на карточке есть фото.
Сервер перечитывает `index.json` раз в 10 минут.

## Важно

- **19 фото ждут повторной проверки Ерлана** (лица, ребёнок, цены, экран ноутбука) — список в `ПРОВЕРКА.md`. Перед деплоем уточните у Ерлана, какие из них убрать.
- **Не переименовывать и не пересжимать** фото: сервер сверяет SHA-256 каждого файла. Любое изменение → фото скрыто.
- `merge.py` ничего не перезаписывает: если место уже с фото или файл уже есть — остановится и покажет причину.
- Фото привязаны к ID из нашего снимка (`osm_…`), поэтому показываются и без 2ГИС.
- Не трогать `scripts/host_photos.py` для этих фото: он удаляет файлы, которых нет в индексе, и меняет формат файла.
