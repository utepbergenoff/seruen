## Проверки

- 355 Python-тестов; одна существующая deprecation-warning FastAPI/Starlette TestClient. Тесты не обращаются к платным API.
- 44 теста интерфейса и маршрутов. Python-набор дополнительно включает реальный JS→FastAPI прогон всех восьми функций на синтетических данных, без подмены ответов API.
- Ruff и `git diff --check` без ошибок.
- Исходные 30 сценариев: 30 ответов с карточками, 78/78 бюджетов соблюдены, 0 выдуманных ID, 0 неподтверждённых утверждений «открыто», проверка приватности логов пройдена.
- Спецификация Ерлана (6 × 5): 30/30 на реальной базе 1 251 мест, режим no_ai, BM25+LSA. Это структурная проверка, не ручная оценка релевантности и не живой Gemini.
- Валидатор новых наборов: valid, все пять коллекций пусты. Искусственные места существуют только во временных тестах и подписанных примерах.

## Деплой и общая приёмка

Порядок выпуска: PR в main → существующий Render Free, без изменения ключей, тарифа и исходной базы → проверка Live, health, CORS, старых рекомендаций и новых API. Результат облачной проверки фиксируется отдельно после деплоя; эти локальные тесты её не заменяют. Новые пустые коллекции должны давать неизвестные условия/пустые удобства/awaiting_data, а не фиктивные сведения.

Живые Gemini и 2ГИС зависят от их текущих квот. Последний статус до этой работы: Gemini HTTP 429; новые локальные тесты не означают восстановление живого ИИ. Никакой автоматический переход на платный тариф не добавлен.

Открыты командные пункты: реальные данные/фото/права от Ерлана, публикация готового frontend из main Алиханом, совместный прогон на опубликованном сайте и телефоне. Код интеграции включён, монеты убраны. F4/F5/F7/F6 не объявляются готовыми по реальным данным до их получения. Сервер наград/сундуков/аккаунтов не реализован. Публичная приёмка нового UI ещё не выполнена.
