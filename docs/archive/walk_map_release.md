# Прогулка, выбор места, карта и тема — 19 октября 2026

## Что исправлено

- Пустой пересчёт не заменяет прогулку: сервер отвечает 409 `no_replacement_found`, клиент сохраняет маршрут, остановки и кнопки.
- «Замёрзли» и «Устали» в новом интерфейсе запрашивают `keep_stops=true` после проверки `/health.features.nearby_break`. Сервер предлагает одну остановку в помещении до примерно 5 минут пешком, проверяя весь путь с прежними остановками и финишем. Пользователь сначала видит предложение; новая линия применяется только по «Добавить остановку». Времени не хватает — прежний маршрут остаётся.
- Есть отмена запроса, возврат к предыдущему успешному пересчёту и сворачивание/продолжение прогулки. История до пяти вариантов живёт только в памяти вкладки. Прохождение остановок не отменяется, время не увеличивается.
- Нажатие на метку или карточку открывает выбранное место. Назад возвращает полный список, рекомендации и пагинацию без повторного поиска.
- «Начать прогулку» в выбранной карточке строит путь только через этот POI, включая места вне топ-3. Сервер не подменяет недоступный выбор первым результатом. Финиш, расходы, доступность, дети и расписания проверяются.
- Схема / спутник / спутник с подписями. Тема авто / тёмная / светлая. Выбор сохраняется на устройстве; карта и тема не меняют активную прогулку.

## Проверено

- 389 Python-тестов; 64 теста интерфейса; Ruff и проверка diff.
- JS → FastAPI проверка реального контракта с изолированными синтетическими данными.
- Синтетический маршрут к дальнему ТРЦ: остановка согреться добавляется перед ТРЦ, цель и финиш сохраняются. Недостаточный бюджет не разрешает выбросить цель.
- Браузер с реальной локальной базой: выбор Starbucks, второго результата; старт именно к Starbucks; «Замёрзли» без доступной добавки оставляет его на карте; закрытие/продолжение; возврат к списку; спутник и тёмная тема.
- Автотесты проверяют успешное принятие предложения, отмену, возврат, поздние ответы, каталожную точку вне топ-3, сохранность карты и темы.

## Алихану: публикация

1. Взять актуальный `main` после мержа этого PR. Публиковать всю папку `frontend`, включая новый `theme.js`, `features.js`, `app.js`, `i18n.js`, `styles.css`, `index.html`, `about.html`, `sw.js`.
2. Оставить адрес API в `frontend/config.js` прежним. Ключей в клиенте нет.
3. Опубликовать привычным способом на Netlify. Это действие выполняет Алихан — обновление Render само по себе сайт не обновляет.
4. Обновить страницу и проверить: второе/каталожное место → начать → «Замёрзли» → предложение или честное отсутствие → маршрут остаётся. Проверить «Назад», карту и тему на телефоне.
