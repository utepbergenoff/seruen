# Интеграция реальных данных — 18.10.2026

Снимок Ерлана: 1 251 место Астаны. Повторный сбор и вызовы Gemini/Google при интеграции не выполнялись; ключи отложены пользователем.

## Исправления

- Раньше загрузчик удалял 96 записей по одинаковому названию в пределах 80 м. Теперь общий заголовок («Детская площадка», «Сквер») не является признаком дубля. Для именованных мест сравниваются категория, имя и расстояние менее 30 м; повторный ID по-прежнему удаляется. Все 1 251 записи проходят без потерь и отказов.
- `name_generic`, `tags_inferred`, `google_place_id`, `description_url` сохранены в контракте. Отдельные безымянные площадки не считаются одной сетью. Предположенные удобства обозначаются как типичные для категории, а не как проверенные факты.
- BM25 + LSA (64 измерения) пересобраны на 1 251 месте. UTF-8 явно задан при чтении JSON; `tzdata` установлен для ZoneInfo на Windows. Эти исправления Ерлана сохранены. Локальные проверки интеграции выполнены на macOS; отдельный повторный запуск Windows не проводился.
- Для S1 ограничена пешая дорога до 15 минут в одну сторону, для S5 уточнены категории и сохранён резерв аэропорта 60 минут, для общего ночного S6 уточнены категории.
- Парсер понимает пробелы вокруг времени, разделение дневных правил запятыми и списки дней с пробелами. Из 270 непустых расписаний распознаются 268; два неоднозначных правила с праздниками остаются `unknown`.

## Ночь и «открыто сейчас»

S2 и S4 проверены при одинаковом времени 01:04: ночная заметка есть в обоих случаях; неосвещённые открытые пространства исключаются. Различие из прежнего сообщения команды при одинаковых условиях не воспроизвелось. Кнопки демо передают фиксированный час (например, 14:00), поэтому их результат может отличаться от текущей ночи. Теперь каждый такой ответ явно сообщает дату и время демо в Астане.

У двух парков в исходном OSM указано `24/7`: это позволяет вычислить `open` по расписанию, но не отменяет ночные фильтры безопасности и не подтверждает фактическую работу. Отсутствующие часы не заменяются на `open`.

- `pytest`: **166 passed**, одно предупреждение библиотеки тестового клиента; Ruff: PASS.
- [30 исходных фикстур на реальном снимке](../../eval/real/report.json): 30/30 ответов с четырьмя частями, 85/85 карточек в бюджете, 0 выдуманных ID, 0 `open` без расписания/источника, 30/30 извлечённых намерений, кеш 6/6.
- [30 сценариев Ерлана](../../eval/real_spec/report.json): **30/30** проходят явные критерии количества, категорий, пешего времени, бюджета и безопасности. Прогон использует заданное сценариями время (`simulate=true`); S5 проверяет время посещения отдельно от 60 минут резерва.
- 270 мест имеют часы, 22 описания — Wikipedia, 1 229 — шаблонные, доступность известна у 64. Данные сборщика не равны проверке на месте.

Это автоматические локальные проверки. Ручные оценки 3×30, живой Gemini и полная приёмка интерфейса ими не заменяются. Публичное развёртывание подтверждено: [отчёт деплоя](real_data_deployment_verification.json), 6/6 демо и 30/30 сценариев по HTTPS; подробности в [handoff](handoff.md).

## Воспроизведение

```bash
make setup
cp .env.example .env
make index
make test
POI_PATH=data/poi.json DATA_KIND=real .venv/bin/python eval/run.py --output eval/real
.venv/bin/python eval/run_spec.py
make run
```

Все изменения команды проходят через `feat/*` → PR → `main`. Для существующего Render Free: ветка `main`, `POI_PATH=data/poi.json`, `DATA_KIND=real`; build пересобирает индекс. Другой сервис или платный тариф не требуется.
