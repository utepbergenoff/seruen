# Проверка функций прогулки на людях

Статус: **не проведена**. Ниже протокол и пустые таблицы. Не заполнять заранее и не дописывать участников, которых не было.

## Участники

6–8 человек, если реально в срок; фактическое число указать честно. Условные номера P1…P8.
Не записывать имена, телефоны, домашние адреса. Возраст — группой (до 18 / 18–25 / 26–40 / 40+), только с согласия.

## Задачи (2–3 на человека, без подсказок, куда нажимать)

1. «Вы у Байтерека, есть полтора часа, на улице холодно. Выберите, куда пойти.»
2. «После первой остановки вы замёрзли — измените прогулку.»
3. «Сохраните план и откройте его без интернета.»

Если человеку помогли — отметить «с помощью» и чем именно.

## Итог для команды (до финального дня)

3–5 главных проблем: шаги воспроизведения, ожидаемое, фактическое, серьёзность, владелец.

Маленькая выборка не доказывает удержание или массовый спрос — в презентации так не писать.
