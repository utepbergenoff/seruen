# Удаление «По атмосфере»

По решению команды функция удалена целиком: элементы интерфейса на RU/KK/EN, запросы к её API, фильтры и бонусы ранжирования, каталог и его схема. `/health` больше не объявляет её; `/atmosphere/examples` и `/atmosphere/profiles` возвращают 404.

Фотографии мест, проверка их принадлежности конкретному заведению и отдельный анализ Gemini сохранены. Маршруты, встречи, остановки, расходы и личные места продолжают использовать прежний контракт.

## Совместимость

Сервер игнорирует только три снятых поля preferences (`atmosphere_example_id`, `atmosphere_profile`, `atmosphere_verified_only`) от старых вкладок и сохранённых прогулок. Они не меняют подбор. Остальные ограничения и финиш сохраняются; неизвестные поля по-прежнему запрещены. Новая версия сайта эти поля не отправляет, даже если подключена к предыдущему серверу.

## Алихану: публикация сайта

1. Забрать актуальную `main` после мержа изменения удаления функции.
2. Опубликовать целиком папку `frontend/` в существующий сайт Netlify, включая `sw.js`, `features.js`, `i18n.js`, стили и каталог фотографий. Сборка не нужна; адрес API не меняется.
3. Проверить, что опубликованный `/sw.js` содержит `seruen-v33-no-atmosphere`. Перезагрузить открытую вкладку после обновления.
4. Проверить отсутствие «По атмосфере» во всех языках, обычный поиск, старт к выбранному месту и встречу с сохранением маркеров A/B. Предыдущее исправление точки B уже входит в эту версию.

Публикация бэкенда на Render сама по себе не обновляет HTML/JS сайта Netlify. До публикации Алиханом в старой вкладке может оставаться прежняя кнопка.

## Проверки

- 477 тестов Python: поиск/маршруты/фото/встречи, отсутствие снятых API и схем, миграция старых preferences, экспорт/открытие/пересчёт сохранённой прогулки.
- 126 тестов интерфейса: отсутствие панели и запросов даже при старом `/health`, RU/KK/EN, обычный поиск и сохранённые сценарии прогулок.
- Ruff и `git diff --check` — без ошибок; валидатор четырёх оставшихся наборов данных — valid.

Эти результаты относятся к коду релиза; публикацию сайта проверяем отдельно после обновления Netlify.
