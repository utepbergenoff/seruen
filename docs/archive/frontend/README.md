# Интерфейс Серуен

Владелец — Алихан. [Сайт](https://seruen-astana.netlify.app), [бэкенд](https://seruen-backend-f36d.onrender.com), [общее описание и ограничения](../../../README.md).

Это статический сайт: HTML, CSS, JavaScript, Leaflet и PWA. Обязательного этапа сборки нет. Node.js 22+ используется для тестов.

## Локальный просмотр

Из корня репозитория:

```bash
python3 -m http.server 5173 --directory frontend
```

Открыть `http://localhost:5173`. Этот origin разрешён в стандартном CORS бэкенда.

В `frontend/config.js` по умолчанию указан публичный Render API. Для локального API временно установить `API_URL: "http://127.0.0.1:8000"` и отдельно запустить бэкенд. Перед публикацией вернуть HTTPS-адрес Render. Пустой `API_URL` требует общего сервера / прокси; обычный статический сервер Python API не обслуживает.

Ключей Gemini, 2ГИС и Google во фронтенде быть не должно.

## Основные файлы

| Файлы | Назначение |
|---|---|
| `index.html`, `styles.css`, `editorial.css`, `alignment.css` | Структура страницы, актуальный дизайн, адаптивность и выравнивание |
| `app.js`, `config.js` | Основной поиск, карточки, источники и адрес API |
| `route.js`, `features.js` | Активная прогулка, финиш, пересчёты, удобства и сохранение |
| `experiences.js`, `experiences-i18n.js` | Встреча вдвоём, зимний режим, достопримечательности |
| `i18n.js`, `theme.js`, `layout.js` | Языки, темы, размер панели и карта |
| `storage.js` | Локальные списки, заметки и разрешённые сохранённые планы |
| `presets.json`, `scenarios.json` | Общественные ориентиры и шесть идей для прогулки |
| `about.html`, `about-i18n.js`, `about.css` | Данные, приватность и ограничения |
| `sw.js`, `manifest.json`, `icons/` | Оболочка PWA; это не полная офлайн-карта |
| `img/places/index.json`, `img/places/` | Фото; сервер дополнительно проверяет свой реестр и хеш |
| `vendor/leaflet/` | Локальная библиотека карты |

Дополнительные кнопки проверяют поддержку в `/health.features`. Наличие флага не заменяет проверку готовности данных в `/features/status`.

## Поведение, которое нужно сохранять

- Начать маршрут именно к выбранному месту, включая место вне топ-3.
- Сохранить цель при «Замёрзли» / «Устали»; применить остановку только после выбора и успешного пересчёта.
- Во время прогулки показывать одну активную линию. Ошибка и запоздавший ответ не возвращают конкурирующие маршруты.
- Сохранять список, выбор и точки A/B при переходах «Назад», загрузке и ошибках.
- Финиш задаётся в контексте: остаться у места, вернуться или выбрать другую точку. Выбранная точка видна на карте.
- Раздел «Идеи для прогулки», заметный контекст, перенос длинных подписей на трёх языках и обе темы.
- Часы и атрибуты показываются с источником, датой и неопределённостью. Фото и анализ отделены от описания места.
- Геолокация не блокирует ручной выбор. Поздний GPS-ответ не меняет уже выбранный старт.

Во встрече B — выбранная пользователем точка второго участника, не его живая геолокация. При старте маршрута встречи финиш — выбранное заведение.

## Проверки и публикация

```bash
npm ci
npm test
```

На проверенной сборке 20.10.2026 прошли 144 теста. Это не проверка всех телефонов и браузеров. Полный Python-набор также содержит интеграцию JS → FastAPI и требует установленных Node-зависимостей.

Публикует Алихан: актуальная согласованная папка **`frontend/` целиком**, включая стили, фотографии и `sw.js`. Если его опубликованная ветка новее `main`, сначала объединить изменения. Не заменять её старой папкой ради одного файла.

Контроль после публикации: версия кеша, второе/третье выбранное место, финиш, остановка по пути, возврат к списку, встреча A/B, расписание, темы, мобильный экран. Деплой Render не публикует сайт.

На HTTP-проверке 20.10.2026 публичный сайт отдавал `seruen-v43-tomi-merge` и новый заголовок. Полный пользовательский прогон именно этой публикации отдельно не заявляется.

## Ограничения

Карты, погода, онлайн-геометрия и внешние API требуют сети. Спутник имеет ограниченное разрешение; его лицензия должна быть учтена для коммерческого запуска. Пеший OSRM не подтверждает входы и состояние переходов. Сохранённый план не равен свежему расписанию.

Поиск «По атмосфере» и геймификация удалены. Старые отчёты с монетами, автомобильным OSRM или иным дизайном описывают прежние версии и не являются текущей инструкцией.
