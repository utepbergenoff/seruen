# Архив разработки

Рабочие заметки команды за время разработки (октябрь 2026): передачи задач между участниками, отчёты о релизах,
аудиты и сырые результаты проверок живого API.

Это история, а не текущее описание проекта: статусы, квоты, адреса развёртывания и числа в этих файлах
относятся к дате, указанной в каждом из них. Актуальное описание — в [README](../../README.md) и в документах
папки [docs](..).
