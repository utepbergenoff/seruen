# Релиз: рекомендации Gemini, RAG и привязка фото

19.10.2026. Изменения подготовлены от main после PR #53; дизайн Алихана сохранён.

## Поведение

- Gemini пишет показываемые «почему» и «что делать» для проверенных мест из локальной базы и 2ГИС. ID, порядок, финиш и длительности контролирует сервер.
- Генерация ссылается на факты; чужие ID, неизвестные ссылки, числовые обещания, цены, гарантии и неподтверждённые удобства отвергаются. Смешанные карточки честно маркируются.
- Запрошенные удобства учитываются только при прямом подтверждении; явные Wi-Fi/розетки из 2ГИС теперь участвуют в подборе. Генерированные описания исключены из поискового индекса.
- Общий зал Хан Шатыра не выдаётся за Fame City. В публичной подборке 39 разрешённых привязок фото к 15 объектам. Остальные требуют проверки; источник, авторство и контрольная сумма сохранены.
- Новая карточка сразу показывает занятие и время на месте. Серверный маршрут через остановку из PR #53 включён в этот пакет фронтенда.

## Проверки

- 464 Python-теста и 122 JS-теста, Ruff — успешно.
- `eval/real/report.json`: 30/30 запросов, 78/78 карточек в бюджете, 0 чужих ID, 0 «открыто» без данных, логи без текста запроса/координат.
- `eval/real_spec/report.json`: 30/30 сценариев Ерлана, реальный снимок, BM25+LSA версии 2.
- Это локальные проверки. Состояние живого API и подтверждённые генерации после деплоя фиксируются в `grounded_rag_live.json`. Человеческие баллы полезности не выдумывались.

## Алихану

Публиковать **весь frontend из актуального main**, сохраняя существующий адрес API.
Версия service worker: `seruen-v30-grounded-rag`. Обязательны `app.js`, `sw.js`, `about.html`,
`img/places/index.json` и остальные файлы папки: нельзя публиковать старую ветку дизайна поверх релиза.
После публикации обновить вкладку и проверить:

1. S1: «почему», занятие и время видны сразу, текст ИИ помечен, неизвестные удобства не обещаются.
2. S2 у Хан Шатыра: игровые центры внутри ТРЦ рекомендуются; чужого интерьера в Fame City нет.
3. Выбрать вторую карточку → начать прогулку: цель соответствует выбору.
4. Согреться/устали → выбрать остановку по пути: маршрут проходит через неё, первоначальный финиш остаётся; отмена работает.
5. Назад ко всем местам возвращает топ-3; режим карты, тема и контекст сохранены.
6. «О данных и приватности» описывает актуальную генерацию и проверку фото.

Не использовать один `mode=ai` как источник всех карточек: смотреть `why_source`/`what_to_do_source`.
Бэкенд деплоится отдельно; публикацию Netlify выполняет Алихан.

## Ерлану

Новые фото сначала проверять на соответствие конкретному филиалу. Снимок общего зала ТРЦ не является
снимком арендатора. Для расширения указать POI, источник, автора/лицензию и SHA-256 в
`data/photo_identity_review.json`, добавить материал в опубликованный index и проверить тесты.
Сборщик Commons теперь выдаёт кандидатов в `data/photo_candidates.json`, не публикует их автоматически.

Для S1 особенно нужны проверенные розетки, Wi-Fi и условия работы в конкретных кофейнях.
Тишину нельзя выводить из фото или категории. Отметить источник и дату, неизвестное не заполнять догадкой.
Проверить естественность казахских текстов и провести пользовательскую оценку 6 демонстрационных сценариев.

## Стоимость и границы

Тот же Render Free, те же ключи и квоты; никаких платных API/ресурсов/подписок не добавлено.
Обычно одна генерация на новый запрос, максимум один исправляющий повтор внутри общего таймаута;
429 не повторяется. Бесплатная квота может исчерпаться: в этом случае работает явно помеченный режим по правилам.
Презентация и YouTube-видео в этот релиз не входят. Нет заявления о полной готовности к массовой эксплуатации.
