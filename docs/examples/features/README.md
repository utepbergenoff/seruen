# Примеры версии 1

JSON получен выполнением FastAPI TestClient на **синтетических фикстурах** из `tests/test_feature_expansion.py`. Это не реальные места, права или результаты публичного API. Данные production остаются пустыми до передачи Ерланом.

Каждый файл содержит метод, путь, полный запрос, HTTP-статус и фактический ответ. `plan_ok` — обычный план, `plan_empty` — всё исключено, `plan_error` — неизвестный ID, `comfort` — удобство, `offline_export` — разрешённый тестовый снимок. Даты фиксируют момент создания примеров; для нового запроса использовать текущее состояние. Поле `fixture` — метаданные примера, не поле API.
