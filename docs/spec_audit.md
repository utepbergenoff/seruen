## Найденное в аудите и исправления

1. Текст Gemini отбрасывался после вызова: теперь показывается проверенная генерация с честным источником.
2. Общие действия для баров: уточнён промпт и резервное действие по категории.
3. Атрибуты удобств 2ГИС не участвовали в поиске: теперь явные Wi-Fi/розетки учитываются, предположения не усиливают рейтинг.
4. Фото торгового зала привязаны к Fame City: введена проверка точного объекта и байтов; неподтверждённые материалы скрыты.
5. README и документ сценариев устарели: переписаны по текущему коду и реально выполненным проверкам.
6. На момент исходного аудита Netlify был v28: готов весь frontend v31 для публикации Алиханом.

Текущий прогон: 472 Python + 123 JS, Ruff, 30/30 исходных фикстур (78/78 карточек в бюджете), 30/30 сценариев Ерлана.
Подробности и границы проверки: grounded_rag_release.md. Живые генерации, время и версия деплоя:
grounded_rag_live.json после серверного релиза. Успешные локальные тесты не заменяют эту проверку.

## Что не следует обещать

Ручных пользовательских оценок пока нет. Данные и часы могут устареть; проходимость и безопасность не гарантированы.
Удобства, доступность и атмосфера подтверждены лишь у части мест. Бесплатные внешние API имеют квоты.
Фото не подтверждает свободные места, тишину и текущую обстановку. LSA — корпусные, а не нейросетевые эмбеддинги.

RU/KK/EN, встреча вдвоём, зимние условия и остановки — дополнительные возможности.
Полное согласование интересов группы из 3–5 человек, живая афиша и автоматический маршрут из трёх посещений
не заявлены как реализованные. Это дополнительные цели ТЗ, не блокирующие сдачу первого кейса.
