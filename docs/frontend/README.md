# Поток C (Алихан): сайт, карта, мобильная версия, видео

**Сайт:** https://seruen-astana.netlify.app · **бэкенд:** https://seruen-backend-f36d.onrender.com

Стек — **план Б** из командного плана: одна HTML-страница + чистый JavaScript + Leaflet, без сборки.
Код: `seruen/frontend/`. Всё, что сайт ждёт от бэкенда, описано в `CONTRACT_FOR_BACKEND.md`.

## Посмотреть у себя

```bash
cd frontend && python3 -m http.server 8080
```

Открыть http://localhost:8080 — карта, кнопки и сценарии работают. Ответы (карточки) появятся, когда в
`frontend/config.js` будет адрес бэкенда Томирис: `python scripts/set_api_url.py https://…`.

Полезные ссылки для демо (ничего не печатать):

| Ссылка | Что делает |
|---|---|
| `/?scenario=S1` … `S6` | запускает сценарий из меню «Сценарии» |
| `/?at=2026-10-18T15:00` | симуляция времени (днём показать то, что будет в 15:00, или ночь в 23:00) |
| `/?preset=khan` | стартовая точка (mega, expo, khan, baiterek, nurly, airport) |
| `/?lang=kk`, `/?pirate=1`, `/?chip=0` | язык, пиратский режим, сразу нажать чипс №0 |

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css`, `app.js` | экран, вёрстка (ноутбук + телефон), логика |
| `i18n.js` | подписи RU / KK / EN (казахский — проверить носителю языка) |

| `scenarios.json` | 6 сценариев — запасной вариант, если `GET /scenarios` не отвечает |
| `about.html` | «О данных и приватности» |
| `manifest.json`, `sw.js`, `icons/` | PWA: установка на экран, работа оболочки офлайн |
| `vendor/leaflet/` | Leaflet 1.9.4 локально (работает без CDN) |

## Честные ограничения сайта

- Карта (тайлы OSM) и погода требуют интернета; оболочка сайта открывается и без него.
- Линия маршрута строится публичным демо-сервером OSRM (у него профиль для машин), поэтому линия может идти по проезжей
  части; минуты считаются по формуле расстояние × 1,3 / скорость. Если OSRM не отвечает — прямые линии.
- Для линии маршрута в OSRM уходят координаты мест и точка пользователя, округлённая до ~100 м (только по нажатию кнопки).
- Казахские подписи написаны с помощью ИИ — нужна вычитка носителем языка.
