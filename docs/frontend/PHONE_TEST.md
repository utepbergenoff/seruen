# Проверка на телефоне и установка как приложение (задача C6)

Нужна **публичная https-ссылка** сайта (например `https://seruen-astana.netlify.app`).
По `http://` геолокация на телефоне не работает.

## iPhone (Safari)

1. Откройте приложение **Safari** (не Chrome!) → в адресной строке наберите ссылку → **Перейти**.
2. Должна появиться карта, сверху «Серуен», кнопки «Сценарии», «KZ RU EN», 🏴‍☠️.
3. Нажмите **«📍 Моё местоположение»** → во всплывающем окне **«Разрешить»** → точка «Я здесь» прыгнет к вам
   (если вы не в Астане — появится сообщение и точка встанет в центр, это нормально).
4. Нажмите чипс **«☕ Кофе и розетка»** → через 1–2 секунды карточки (листайте вниз).
5. Установка: кнопка **«Поделиться»** (квадрат со стрелкой вверх, внизу экрана) → пролистайте список →
   **«На экран «Домой»»** → справа сверху **«Добавить»**.
6. На рабочем столе телефона появится иконка с компасом **«Серуен»**. Нажмите — сайт откроется
   **на весь экран, без адресной строки**. Это и есть PWA ✓.

## Android (Chrome)

1. Откройте **Chrome** → наберите ссылку.
2. Повторите шаги 3–4 как для iPhone (разрешение: **«Разрешить»** / **«При использовании приложения»**).
3. Установка: **⋮** (три точки справа сверху) → **«Установить приложение»** (или **«Добавить на главный экран»**) →
   **«Установить»**.
4. Иконка «Серуен» на главном экране → открывается на весь экран ✓.

## Что проверить глазами (по чек-листу вс 23:00)

- [ ] «Сценарии» → S1 … S6: каждый даёт карточки за 1 нажатие
- [ ] На карточке: название, «м · мин пешком», цветной статус, «Почему», «Что делать», «На месте», полоса времени, «из базы»
- [ ] Нажатие на карточку → карта показывает место
- [ ] «Что я учёл» под ответом; «Показать кандидатов» раскрывается
- [ ] Кнопки «2GIS» и «Google Maps» открывают маршрут в приложении
- [ ] Кнопка «О данных и приватности» (на телефоне — внизу страницы)
- [ ] Повернуть телефон горизонтально — ничего не ломается

Если что-то не так — сделайте скриншот (iPhone: боковая кнопка + громкость вверх; Android: питание + громкость вниз)
и пришлите.
