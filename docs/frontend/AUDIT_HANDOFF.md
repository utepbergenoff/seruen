# Алихану: публикация фронтенда после аудита

18.10.2026. Публикацию выполняет Алихан: у Томирис нет доступа к сайту в Netlify.

1. После слияния PR аудита обновить локальную ветку `main` (`git pull --ff-only`).
2. Проверить `frontend/config.js`: API_URL должен остаться `https://seruen-backend-f36d.onrender.com`.
3. Загрузить **всю папку frontend**, включая новый `route.js`, `sw.js` версии v5 и картинки. Сборка не требуется.
4. Через существующий аккаунт Netlify: `cd frontend && npx -y netlify-cli@23.15.1 deploy --prod --dir . --site seruen-astana`.
5. Обновить страницу и проверить S1–S6, «Что я учёл», кандидатов, три языка; S5 должен показывать запас 60 минут. При переключении сценариев старый ответ не должен заменять новый.
6. На телефонах проверить карту/карточки/кнопки/PWA; убрать мешающий Netlify badge в настройках аккаунта, если тариф позволяет. Результаты записать в PHONE_TEST.md.

Изменения сохраняют дизайн обеих веток фронтенда и исправляют: пустые подписи при холодном старте, поздний GPS, гонку запросов, бюджет мини-маршрута, язык даты, источники описаний и пеший профиль OSRM.

API совместим со старым фронтендом: добавлены поля, старые поля сохранены. Ключи остаются только в Render. `npm ci && npm test` запускает 17 проверок DOM/маршрутов без браузера; это не заменяет ручную проверку телефонов.
