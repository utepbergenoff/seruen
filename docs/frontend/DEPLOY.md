# Деплой сайта (задача C7) — по шагам, по каждому клику

> **Уже опубликовано 17.10:** https://seruen-astana.netlify.app (аккаунт Netlify через GitHub Alikonchik-Kaedahara).
> Бэкенд: https://seruen-backend-f36d.onrender.com (Томирис). Обновить сайт после правок — одна команда:
>
> ```bash
> cd frontend && npx -y netlify-cli@23.15.1 deploy --prod --dir . --site seruen-astana
> ```
>
> Защита «только для команды Netlify» у сайта выключена (иначе жюри видит страницу входа).

Сайт — это папка `seruen/frontend` (обычные файлы, сборка не нужна). Его можно выложить на Netlify
перетаскиванием папки. Сервер (бэкенд) выкладывает Томирис; сайт ходит к нему по адресу из `frontend/config.js`.

## 0. Что нужно до начала

1. Адрес бэкенда от Томирис, вида `https://что-то.onrender.com` (именно **https**).
   Пока его нет — пропустите шаг 1: сайт опубликуется, но ответы появятся только когда будет бэкенд.
2. Аккаунт Netlify (бесплатный). Если нет — его создаём в шаге 2.

## 1. Вписать адрес бэкенда (30 секунд)

1. Откройте приложение **Терминал** (Cmd + Пробел → наберите `Terminal` → Enter).
2. Вставьте команду (замените адрес на адрес Томирис) и нажмите Enter:

```bash
.venv/bin/python scripts/set_api_url.py https://АДРЕС-ОТ-ТОМИРИС
```

3. В ответ должно появиться: `frontend/config.js -> API_URL = https://...`.

(Файл `config.js` руками в TextEdit не правьте: TextEdit меняет кавычки на «ёлочки», и сайт сломается.)

## 2. Опубликовать на Netlify (5 минут)

1. Откройте в Chrome: **https://app.netlify.com/drop**
2. Откройте **Finder** (иконка с лицом в Dock) → в левой колонке нажмите **Рабочий стол** →
   двойной клик по папке **seruen**.
   Вы увидите папку **frontend**.
3. Поставьте окна рядом: Finder слева, Chrome справа.
4. Зажмите мышью папку **frontend** и перетащите её в пунктирную рамку **«Drag & drop to publish instantly»
   / «Drop here»** на странице Netlify. Отпустите кнопку мыши.
   (Если перетаскивание неудобно: нажмите в рамке ссылку **folder** → в окне выберите
   Рабочий стол → seruen → **frontend** → кнопка **Upload / Выбрать**.)
5. Подождите 10–30 секунд — появится ссылка вида `https://случайное-имя-12345.netlify.app`.
6. Netlify предложит **сохранить сайт** (иначе ссылка через время пропадёт): нажмите кнопку
   **Sign up / Claim site / Log in**. Выберите **Sign up with GitHub** (или **Email**) → разрешите доступ →
   вернётесь в панель сайта.
7. Красивое имя: в панели сайта слева нажмите **Site configuration** (или **Project configuration**) →
   **Change site name** (или **Change project name**) → впишите `seruen-astana` → **Save**.
   Новая ссылка: `https://seruen-astana.netlify.app` (если имя занято — `seruen-astana-2026`).
8. Откройте ссылку в Chrome: должна появиться карта и кнопки. Нажмите **«Сценарии» → S1** — через секунду
   появятся карточки.

## 3. Отдать ссылку Томирис (CORS)

Напишите Томирис в чат: «Адрес сайта: https://seruen-astana.netlify.app — добавь его в CORS_ORIGINS на бэкенде».
Пока она не добавит — сайт покажет «Сервер недоступен».

## 4. Проверить автоматически (2 минуты)

В Терминале:

```bash
.venv/bin/python scripts/check_site.py https://seruen-astana.netlify.app
```

Внизу должно быть `N/N checks passed`. Строки `FAIL` — пришлите мне.

## 5. Проверить на телефонах (у всех троих) — см. `PHONE_TEST.md`

## 6. Как обновить сайт после правок

1. https://app.netlify.com → ваш сайт **seruen-astana** → вкладка **Deploys**.
2. Внизу страницы рамка **«Need to update your site? Drag and drop your site output folder here»** —
   перетащите туда папку **frontend** ещё раз. Через 10–30 секунд ссылка покажет новую версию.

## Вариант Б: Vercel (если Netlify не пошёл)

1. https://vercel.com → **Sign Up** → **Continue with GitHub**.
2. Нужен репозиторий на GitHub. **Add New…** → **Project** → у вашего репозитория **Import**.
3. **Root Directory** → **Edit** → выберите `frontend` → **Continue**.
4. **Framework Preset**: `Other`. Build Command — пусто. **Deploy**.
5. Через минуту — ссылка `https://….vercel.app`. Дальше шаги 3–5 выше.

## Если адреса бэкенда ещё нет

Сайт можно опубликовать и без него: карта, кнопки и сценарии откроются, но на запрос будет «Сервер недоступен».
Когда Томирис пришлёт адрес — выполните шаг 1 и обновите сайт (шаг 6).
