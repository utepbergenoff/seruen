## Алихану

1. Использовать базовый адрес `https://seruen-backend-f36d.onrender.com`; брать `request` из GET /scenarios и отправлять POST /recommend.
2. Отрисовывать рекомендации как альтернативы, не как суммарный маршрут; бюджет каждой карточки — recommendations[].budget_breakdown.
3. Обязательно показывать mode, data_kind=sample, notes, safety, disclaimer и метки источников. При sample внешние links пустые.
4. Для панели кандидатов использовать POST /candidates с тем же JSON: это не раскрывает локацию в URL внешнего прокси.
5. Сообщить фактический домен фронта, чтобы добавить его в CORS_ORIGINS, и подтвердить docs/api.md. Сейчас разрешены только localhost:5173, 127.0.0.1:5173 и localhost:3000.
