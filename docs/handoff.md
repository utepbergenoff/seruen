Хостинг выбран пользователем: Render, план Free, один Python web service, без БД/диска/платного ключа, автодеплой выключен. Ветка [codex/backend-rag](https://github.com/utepbergenoff/seruen/tree/codex/backend-rag) опубликована и проверена по удалённой ссылке.

**Деплой пока заблокирован доступом к приватному репозиторию.** Render отклонил создание сервиса: repository URL invalid or unfetchable. В подключённых deployment credentials аккаунта tomirizz доступен только другой репозиторий; аккаунта владельца utepbergenoff в установках Render нет. Новый сервис не создан, публичного адреса нет. Это внешний блокер B11, не ошибка запуска Python.

После обнаружения ограничения Томирис выбрала: оставить готовую ветку и инструкцию, деплой пока не продолжать. Платные ресурсы и новые сервисы не созданы.

Владельцу utepbergenoff: открыть https://github.com/apps/render/installations/new, установить/настроить Render только для seruen. Затем выбрать этот репозиторий в Render, ветку codex/backend-rag, настройки ниже и план Free. Build: `pip install -r requirements.txt && python scripts/reindex.py`.
Start: `python -m scripts.serve`.
Переменные: HOST=0.0.0.0, POI_PATH=data/poi_sample.json, DATA_KIND=sample, PYTHON_VERSION=3.12.10; порт предоставляет Render.

Render Free засыпает после 15 минут без трафика; следующий старт может занять около минуты ([условия Render](https://render.com/docs/free)). Перед видео открыть /health и прогреть сценарии. Free ограничен квотами сборок/трафика; платный план не требуется для этой конфигурации.

## Алихану

1. Брать `request` из GET /scenarios и отправлять POST /recommend.
2. Отрисовывать рекомендации как альтернативы, не как суммарный маршрут; бюджет каждой карточки — recommendations[].budget_breakdown.
3. Обязательно показывать mode, data_kind=sample, notes, safety, disclaimer и метки источников. При sample внешние links пустые.
4. Для панели кандидатов использовать POST /candidates с тем же JSON: это не раскрывает локацию в URL внешнего прокси.
5. Сообщить фактический домен фронта, чтобы добавить его в CORS_ORIGINS, и подтвердить docs/api.md. Сейчас разрешены только localhost:5173, 127.0.0.1:5173 и localhost:3000.
